## Apple App Store Assets

- [ ] Final iPhone screenshots
  Use one accepted 6.9-inch portrait size such as `1320 x 2868`.
- [ ] Final iPad screenshots
  Required because the app currently supports iPad; use one accepted 13-inch portrait size such as `2064 x 2752`.
- [ ] App preview video, if marketing wants one
  Optional, but poster frame and preview review notes must also be prepared if used.
- [ ] Final App Store icon artwork
  The repo currently contains a clean placeholder, not final brand art.

## Google Play Assets

- [ ] Play Store app icon
  Required store-listing icon; use a higher-fidelity version of the launcher icon.
- [ ] Feature graphic
  Required to publish the main store listing.
- [ ] Phone screenshots
  Minimum two screenshots required; four `1080 x 1920` portrait screenshots are strongly recommended for merchandisable placement.
- [ ] 7-inch and 10-inch tablet screenshots
  Recommended for large-screen merchandising and tablet listing quality.
- [ ] Optional preview video
