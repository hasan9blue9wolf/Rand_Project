# Store Placeholder Assets

These SVG files are editable working canvases for marketing/design handoff. Export them to PNG or JPEG before uploading to App Store Connect or Play Console.

Included placeholders:

- Apple iPhone screenshot canvas
- Apple iPad screenshot canvas
- Google Play phone screenshot canvas
- Google Play tablet screenshot canvas
- Google Play feature graphic canvas

Use the live app UI for the final exported screenshots. Do not submit these placeholder graphics to either store.
